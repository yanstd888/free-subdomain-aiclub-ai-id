## ⚡ Why AICLUB Free Subdomains?

**AICLUB (`aiclub.ai.id`)** is a managed free subdomain registry and DNS routing platform designed for developers, students, AI builders, and small businesses. Unlike traditional GitHub-PR subdomain services that require waiting days for manual pull-request reviews, AICLUB provides a **self-service web dashboard** to claim and route your custom hostname in minutes.

### Key Use Cases:
* **AI Apps & SaaS Demos:** Launch your LLM wrappers, agents, and developer tools on a dedicated `.ai.id` or `.eu.cc` address.
* **Developer Portfolios & Digital CVs:** Use clean extensions like `yourname.is-a.cv` or `yourname.is-a.eu.cc` for resumes and personal branding.
* **Free Custom Domain for Static & Cloud Hosting:** Seamlessly map subdomains to **GitHub Pages, Vercel, Netlify, Cloudflare Pages, Render**, or a self-hosted **VPS (Nginx/Docker)**.
* **Niche Web Projects & Communities:** Pick thematic Indonesian `.web.id` extensions for crypto, datasets, prompt engineering, education, or e-commerce catalogs.

## 🚀 Quick Start & Public API

### 1. Check Available Domains via CLI (No Package Required)
You can query the live public domain list directly from your terminal using `curl`:

```bash
curl -fsSL [https://aiclub.ai.id/api/domains-public](https://aiclub.ai.id/api/domains-public)
```

### 2. Clone This Showcase Repository
```bash
git clone [https://github.com/yanstd888/free-subdomain-aiclub-ai-id.git](https://github.com/yanstd888/free-subdomain-aiclub-ai-id.git)
cd free-subdomain-aiclub-ai-id
```

### 3. Connect Your Hosting Platform in 4 Steps
1. **Pick a Base Domain:** Open the [AICLUB Domain Catalog](https://aiclub.ai.id/domains/) and select from `.ai.id`, `.web.id`, `.cv`, or `.eu.cc`.
2. **Claim Your Subdomain:** Log in at [aiclub.ai.id/masuk](https://aiclub.ai.id/masuk) and register your desired name (e.g., `myproject.aiclub.ai.id`).
3. **Point Your DNS Target:** Enter the CNAME / IP target provided by Vercel, GitHub Pages, Netlify, Cloudflare Pages, or your VPS.
4. **Add Custom Domain in Host:** Add your new `*.aiclub.ai.id` address in your hosting provider's *Custom Domains* settings to activate HTTPS/SSL.

**AICLUB (`aiclub.ai.id`)** adalah platform penyedia **subdomain gratis Indonesia** yang dirancang untuk developer, kreator, mahasiswa, startup, komunitas, dan UMKM. Dapatkan alamat website profesional yang singkat dan mudah diingat tanpa harus membeli domain berbayar terlebih dahulu.

### Keunggulan Subdomain Gratis AICLUB:
* **Ekstensi Domain Unik & Kredibel:** Tersedia pilihan `.ai.id` (sangat cocok untuk proyek AI & SaaS), `.web.id` (untuk website lokal & SEO Indonesia), `.cv` (untuk portofolio kerja/CV online), dan `.eu.cc`.
* **Kompatibel dengan Hosting Populer:** Mudah dihubungkan ke **GitHub Pages, Vercel, Netlify, Cloudflare Pages**, maupun **VPS pribadi (Ubuntu/Docker/aaPanel)**.
* **Tanpa Ribet Pull Request:** Pengaturan DNS dilakukan langsung melalui *dashboard* web yang praktis disertai [Panduan Setup Bahasa Indonesia](https://aiclub.ai.id/panduan/setup/).

### Cara Mendapatkan Subdomain Gratis di AICLUB:
1. Kunjungi halaman [**Katalog Domain AICLUB**](https://aiclub.ai.id/domains/) dan pilih ekstensi dasar yang sesuai dengan topik proyek Anda.
2. Masuk ke [**Dashboard AICLUB**](https://aiclub.ai.id/masuk) dan klaim nama subdomain yang masih tersedia.
3. Masukkan *target hostname* (CNAME) atau IP Address dari layanan hosting Anda.
4. Pasang *Custom Domain* di pengaturan Vercel / GitHub Pages / Netlify Anda, dan website siap diakses secara publik lengkap dengan SSL (HTTPS).
